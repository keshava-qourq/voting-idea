# Voting Idea

Build a small Idea Voting Board with sign up.

Features
1. Sign up with email and password. Log in and log out.
2. Post an idea (title, short description). Logged-in users only.
3. List ideas by votes, highest first. Anyone can view.
4. Upvote an idea. One vote per user per idea.

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest            # on PostgreSQL: see TESTING.md
ruff check .
ruff format .
```
